## Python Mini Project
This repository contains two simple python nimi project devveloped for learning python programming concept

## 1. File Handling Mini Project
A lightweight python application leveraging buil-in file handling capabilities to efficiently store,organize, and manage student  data
dynamically without a traditional database.

### Features
1.Add a new student record
2.View all student record
3.Search a student by roll number
4.Update student details
5.Delete a student record
6.Store data in a text file

## 2. Numpy Mini Project
An exploratory project built with Numpy to showcase high-performance multi-dimensional array processing, matrix operations, and 
foundational scientific computing.

## features
1.Array engineering
2.Mathematical computing
3.Array manupulation
4.Statistical Insights
